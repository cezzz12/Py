1. Graph Implementation (graph.py)
The core of the project is the Graph class, which supports:

Vertex and edge management
Directed graph representation
Efficient edge tracking
Complex graph operations

Main Features:

Add/remove vertices and edges
Check vertex and edge existence
Calculate in-degree and out-degree
Iterate through vertices and edges
Deep copy graph
Edge cost management

2. Graph Algorithms (bfs.py, service.py)
Two primary graph algorithms are implemented:
->Breadth-First Search (BFS) Shortest Path

    Finds the shortest path between two vertices
Uses a queue-based approach
Reconstructs the path using a parent dictionary

->Lowest Cost Walk

    Finds the minimum cost walk between two vertices
Uses dynamic programming
Handles potential negative cost cycles

3. User Interface (ui.py)
A comprehensive command-line interface that allows:

Interactive graph manipulation
File-based graph import/export
Random graph generation
Path finding
Cost calculation

4. Error Handling (exceptions.py)
exception classes for:

->VertexError: Handles vertex-related errors
->EdgeError: Manages edge-related exceptions
